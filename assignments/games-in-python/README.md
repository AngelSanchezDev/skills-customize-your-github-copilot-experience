
# 📘 Assignment: Games in Python — Hangman

## 🎯 Objective

Build a Hangman word-guessing game in Python using string handling, loops, and conditionals.

## 📝 Tasks

### 🛠️ Implement the Hangman game

#### Description
Create a command-line Hangman game where the program selects a secret word and the player guesses letters until they either reveal the full word or use up their allowed mistakes.

#### Requirements
Completed program should:

- Randomly choose a secret word from a predefined list.
- Show the current word progress with underscores for unknown letters, e.g. `_ _ a _ _`.
- Accept single-letter guesses and prevent repeated guesses from changing the game state.
- Track incorrect guesses and stop the game when the player reaches the maximum allowed mistakes.
- Display a win message when the word is guessed or a lose message when the player runs out of attempts.

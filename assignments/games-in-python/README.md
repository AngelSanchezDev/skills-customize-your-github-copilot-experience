
# 📘 Assignment: Games in Python — Hangman

## 🎯 Objective

Build a playable Hangman word-guessing game in Python that uses strings, loops, conditionals and user input.

## 📝 Tasks

### 🛠️ Task 1 — Implement the Hangman game

#### Description
Create a command-line Hangman game where the program chooses a secret word and the player guesses letters until they either reveal the word or run out of attempts.

#### Requirements
Completed program should:

- Randomly select a secret word from a predefined list.
- Display the current progress of the word using underscores for unknown letters (e.g. `_ _ a _ _`).
- Accept single-letter guesses and ignore repeated letters gracefully.
- Track incorrect guesses and limit the number of wrong attempts.
- End the game with a clear win or lose message and reveal the secret word if the player loses.

### ✨ Optional / Bonus

- Add a simple ASCII-art hangman that progresses with each incorrect guess.
- Load words from an external file or allow different difficulty levels.
